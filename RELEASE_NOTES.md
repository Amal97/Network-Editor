# Network Modifier 1.0.0

The first stable release includes the cross-platform debugging proxy and standalone Chrome extension.

## Highlights

- Capture and inspect HTTP, HTTPS, Fetch, XHR, and WebSocket traffic.
- Modify requests and responses with rules, scripts, breakpoints, mocks, delays, and throttling.
- Replay traffic, export HAR, compare responses, and organize reusable rule profiles.
- Use the proxy for system-wide traffic or the Chrome extension for certificate-free frontend debugging.

## Requirements

- Proxy and CLI: Node.js 20.19 or newer on macOS, Windows, or Linux.
- Extension: Chrome 120 or newer.

See `README.md` and `extension/README.md` for setup and known scope limitations.
